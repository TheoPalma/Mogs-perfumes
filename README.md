# Mogs Perfumes

Site de venda de decants de perfumes desenvolvido com HTML, CSS e JavaScript.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Funcionalidades

- Catálogo de perfumes
- Busca de produtos
- Filtro por marca
- Detalhes dos produtos
- Carrinho de compras
- Controle de quantidade
- Armazenamento do carrinho com LocalStorage
- Design responsivo

## Objetivo

Projeto desenvolvido para praticar desenvolvimento web, organização de arquivos, JavaScript e criação de interfaces.
